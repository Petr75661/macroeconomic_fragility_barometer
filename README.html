Quick start

The fastest way to open the dashboard is to double-click launch_barometer.bat in the parent Barometer folder. Keep its Command Prompt window open while using the site; closing it stops the local server.

First runStreamlit may offer an optional email field. Leave it blank and press Enter. This is Streamlit onboarding, not a Project Barometer requirement.

Run from Command Prompt

cd C:\Barometer\macro_barometer
python -m streamlit run app.py

Explore safely with built-in demo data

cd C:\Barometer\macro_barometer
python main.py --seed-demo
python -m streamlit run app.py

Demo data is useful for learning the interface offline.

Crucial step before going live
If you run the demo script, you must delete data/macro_data.db before running a real live API refresh. Mixing fake demo data with live data will corrupt the normalization math, causing massive chart spikes, sawtooth patterns, and false "Red regime" alerts.

API keys and your .env file

The dashboard works without keys, but FRED and EIA data will be unavailable until you add them. The file .env.example is only a template; create your personal .env copy and keep it private.

cd C:\Barometer\macro_barometer
copy .env.example .env
notepad .env

In Notepad, put each key after its equals sign. Do not use quotation marks or paste the key into the .env.example template.

FRED_API_KEY=paste_your_fred_key_here
EIA_API_KEY=paste_your_eia_key_here
OLLAMA_HOST=http://localhost:11434
Keep keys secret.env is excluded from Git, but do not paste its contents into chat, screenshots, or public issue trackers. Restart the dashboard or run a new refresh after saving changes.

FRED

Provides Treasury yields, high-yield spreads, and financial-stress data.

  1. Create or sign in to a free FRED account.
  2. Open the signed-in FRED API key page and request a key.
  3. Paste it after FRED_API_KEY=.

EIA

Provides weekly distillate and Strategic Petroleum Reserve inventory data.

  1. Complete the free EIA Open Data registration form.
  2. Look for the key in the registration email; check spam if needed.
  3. Paste it after EIA_API_KEY=.

Optional is okay: Yahoo Finance market data needs no key. If FRED or EIA is blank, the app uses cached data where available and displays a fallback warning instead of failing.

Refresh and scheduling

Refresh once now

In the dashboard, choose Refresh Data Now. Alternatively, double-click refresh_barometer.bat in the parent Barometer folder.

cd C:\Barometer\macro_barometer
python main.py --refresh
Ollama can be slowGeopolitical scoring uses your local Qwen model. The app permits up to five minutes per request and one retry. A slow or unavailable model falls back to a neutral score rather than crashing the dashboard.

Windows Task Scheduler: recommended daily collection

  1. Open Task Scheduler and choose Create Basic Task.
  2. Name it Project Barometer daily refresh and select Daily.
  3. For Start a program, choose C:\Barometer\refresh_barometer.bat.
  4. Finish the wizard. The task fetches data, updates today’s cache, records the day’s composite score, and exits.

The Macro Fragility Trend stores one point per calendar day. More than one refresh in a day updates that same day’s point rather than creating duplicates.

Keep the dashboard open

Use the Dashboard refresh interval selector (default: one day) to reread the local cache automatically. Enable Also refresh live sources only when you want the open dashboard to run data collection and Ollama itself. Leaving it off is recommended when Task Scheduler performs the daily refresh.

How to read the dashboard

The Composite Macro Fragility Index runs from 0 to 100. Higher values always represent more stress. It is an analytical early-warning aid—not investment advice.

ZoneScorePlain-English reading
Green0–35Normal regime; buffers are relatively abundant.
Yellow36–60Structural strain; monitor the indicators and buffer burn rate.
Orange61–80Acute fragility; multiple conditions are deteriorating together.
Red81–100Systemic stress; physical, credit, or broad-market disruption may be underway.

Energy & Physical Flow

Watch crude price momentum, refinery margins, and SPR inventory. A falling SPR is a smaller emergency buffer.

Credit & Bonds

Wider high-yield spreads and higher real yields mean credit is becoming more restrictive. The 450 bps line is a high-yield watch level.

AI & Equity Breadth

Rising SPY/RSP can mean leadership is narrowing. VIX, the dollar, and semiconductor/staples leadership should be read by direction, not compared by height.

Geopolitical Intelligence

Local Ollama analyzes RSS headline batches using a strict scoring rubric and chain-of-thought reasoning to prevent hallucination. It scores active physical disruptions, ignoring opinion pieces or hypotheticals.

Troubleshooting

Wildly inaccurate charts or persistent false alarms

If your charts show bizarre sawtooth patterns, massive spikes, or metrics that jump between vastly different baseline scales, your database is contaminated with mixed demo data and live API data. Close the dashboard, delete data/macro_data.db, and run python main.py --refresh to pull a clean history.

“streamlit is not recognized”

Use python -m streamlit run app.py. This does not require Streamlit’s launcher directory to be on Windows PATH.

Missing FRED or EIA data

Confirm the key is in .env, not .env.example; save it; then restart or refresh. Missing keys are non-fatal.

The geopolitics score is neutral or a model warning appears

Check that Ollama is running and that your configured model is installed (e.g. batiai/qwen3.6-35b:iq4). The dashboard deliberately uses a neutral fallback after a timeout or invalid response.

No history line yet

The trend appears after two different calendar days have been collected. Schedule refresh_barometer.bat daily to build it.
